# AirHub | Frontend Client 🎨

A sleek, responsive, and real-time dashboard built with React and Tailwind CSS.

## 🚀 Technical Highlights

*   **Modern Design System**: Custom-built using Tailwind CSS for a premium, lightweight look.
*   **Schema-Driven Forms**: All user inputs are validated via React Hook Form and Zod before being sent to the server.
*   **Real-Time Listening**: Optimized Socket.io client hooks for immediate UI updates without page refreshes.
*   **Strict Type Safety**: Comprehensive TypeScript interfaces shared with the backend for end-to-end reliability.
*   **Performance**: Optimized builds via Vite.

## 🛠️ Tech Stack
- React 18
- TypeScript
- Tailwind CSS
- React Hook Form
- Zod
- Sonner (Notifications)
- Vite

## 🚦 Internal Setup (For Dev)
1. Install dependencies: `npm install`
2. Run in dev mode: `npm run dev`
3. Build for production: `npm run build`
